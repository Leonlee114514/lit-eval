# Projects Page Override

- Layout: toolbar glass bar → new project form as glass card → project library as glass table.
- Empty state: 72px glass icon tile + action button.
- Project rows: selected row uses `--accent-tint`; hover uses `--row-hover`.
- Actions: icon buttons (Pencil / Trash2), touch target >= 36px.
- Motion: direct children enter with `rise-in` stagger (40-250ms).
